# Sprints

Sprints in Agile Pulse are used to plan and track the progress of work over a specific time period. They are unique to a project and contain tasks, members, and deadlines.

## Key Features

### Sprint Properties

- Sprints have a start date, end date, and a current day marker
- Sprints are unique to a project
- Until started, sprints simply have a number of days
- Once started, the specific days of the week are detected (e.g., Mon, Tue, etc.)

### Sprint Management

- Sprints can be added, edited, and archived within a project
- Completed sprints are no longer editable
- Overloaded sprints are visually indicated, and overruns can be moved to another incomplete sprint

### Sprint Content

- Tasks can be created, edited, and removed from a sprint
- Members can be added, edited, and removed from a sprint

## User Interactions

### Creating and Editing Sprints

- Users can create new sprints within a project
- Existing sprint details can be edited

### Managing Sprint Content

- Tasks and members can be added to or removed from a sprint
- Deadlines can be set within a sprint

### Navigating Sprints

- Users can navigate between previous and next sprints

### Viewing Archived Items

- Archived tasks, members, and deadlines from a sprint can be viewed

### Viewing Snapshots

- Users can view snapshots from within a sprint
