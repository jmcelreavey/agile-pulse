# Tasks

Tasks in Agile Pulse are used to track the progress of a sprint. They represent individual units of work that can be assigned, moved, and tracked throughout the sprint lifecycle.

## Key Features

### Task Management

- Tasks can be added, edited, and removed from a sprint
- Tasks can be assigned to members
- Tasks can be moved between members
- Tasks can be extended over multiple days
- Tasks can be marked with different states

### Task Properties

- Tasks have an origin record but can be copied into different sprints and assigned to different members with varying durations
- The state is unique to the origin record

## User Interactions

### Adding and Editing Tasks

- Users can create new tasks within a sprint
- Existing tasks can be edited to update their details

### Assigning Tasks

- Tasks can be assigned to specific members
- Tasks can be moved between members

### Task Duration

- Users can extend tasks over multiple days

### Task State

- The state of a task can be changed to reflect its current status

### Archiving Tasks

- Tasks can be archived when they are no longer needed
