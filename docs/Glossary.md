# Agile Pulse Glossary

The terms used across Agile Pulse and these docs.

- Sprint: A time-boxed period during which specific work has to be completed and made ready for review.
- Project: A high-level organisation structure containing multiple sprints and tasks.
- Task: An individual unit of work within a sprint.
- Member: A user assigned to work on tasks within a sprint.
- Deadline: A specific date within a sprint marking an important event or milestone.
- Snapshot: A point-in-time view of the sprint chart, automatically generated when progressing the current day marker.
- Sprint Chart: The main visual representation of a sprint, showing tasks, members, and deadlines over time.
- Current Day Marker: An indicator on the sprint chart showing the current day of the sprint.
- Dashboard: A central hub providing an overview of multiple projects and sprints.
- Archive: A method of hiding data from the UI without permanent deletion.
- Forecast: The predicted sprint day when the planned work will be finished, worked out from the chart and its snapshots.
- Pace: Work earned so far divided by the work the plan says should be done by now. 100% is exactly on plan.
- At risk: A task likely to miss the sprint, with the reasons the forecast found.
- Focus factor: The share of planned work a person finished in recent sprints, used by the planner to scale their capacity.
- Linked work: A GitHub pull request or issue, or a Jira issue, attached to a task.
- Share link: A public, read-only link to one sprint, which also gives a calendar feed.
- API token: A personal token that lets an MCP client act as you.
